# 测试数据生成脚本

## 功能说明

`generateTestPosts.js` 脚本用于生成测试帖子数据，方便进行功能测试和演示。

## 使用方法

1. 确保在 server 目录下运行：
```bash
cd server
npm run generate-posts
```

2. 或者直接运行脚本：
```bash
node scripts/generateTestPosts.js
```

## 脚本功能

- **清理现有数据**：删除所有现有的帖子、标签、点赞、分享、评论和用户交互记录
- **生成测试帖子**：创建100个随机分布在不同主题的帖子
- **自动添加标签**：每个帖子随机添加1-3个相关标签
- **随机图片**：30%的帖子会包含随机图片
- **随机时间**：帖子创建时间随机分布在最近30天内
- **模拟互动**：20%的帖子会有点赞，10%的帖子会有分享记录

## 数据分布

帖子会随机分布在以下主题中：
- 学术交流
- 资源分享
- 竞赛交流
- 校园生活
- 技术交流
- 表白墙
- 就业兼职
- 校园杂谈

每个主题都有对应的标签和内容模板，确保生成的数据真实可信。

## 注意事项

- 运行此脚本会**删除所有现有的帖子数据**，请谨慎使用
- 脚本会创建一个测试用户（ID=1, email=test@example.com）
- 所有帖子都归属于这个测试用户
- 生成的图片使用 picsum.photos 提供的随机图片服务

## 自定义配置

如需修改生成的帖子数量或内容，可以编辑 `generateTestPosts.js` 文件中的：
- `topicData` 对象：修改主题、标签和内容模板
- 循环次数：修改 `for (let i = 0; i < 100; i++)` 中的数字
- 图片概率：修改 `randomImage()` 函数中的概率值
- 互动概率：修改点赞和分享的概率值
